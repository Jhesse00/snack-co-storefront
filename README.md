# SNACK CO. — E-Commerce Storefront Prototype 🍿

> An early-stage snack e-commerce brand storefront prototype created for an **NYU AI-First Business Venture Assessment**, visually inspired by **LesserEvil**'s playful, colorful, premium snack aesthetic.

---

## 🌟 Live Storefront Demo
- **Live URL**: https://jhesse00.github.io/snack-co-storefront/

---

## ✨ Features
- **LesserEvil-Inspired Aesthetic**: Soft pastel backgrounds, oversized friendly typography (Fredoka + Plus Jakarta Sans + Outfit), wavy scallop dividers, and rounded pill elements.
- **High-Fidelity 3D Vector Pouch Mockup**: Realistic SVG snack pouches with metallic crimped ridges, foil reflections, and custom ingredient doodles for Original Sea Salt, Sweet Cinnamon Glaze, and Savory Herb & Garlic.
- **Dynamic Hero Flavor Switcher**: Switch flavors directly on the hero section to see the packaging and background hue transition in real time.
- **Interactive Multi-Pack Bundles**: Select Single bags, 3-Packs, 6-Pack Party Boxes, or 12-Pack Semester Stashes.
- **Slide-Out Cart Drawer**: Real-time Free Shipping Progress Bar ($35 goal), quantity increment/decrement, and demo coupon support (`NYUAI` for $5 off, `FREESHIP`).
- **Simulated Checkout Flow**: Clean Shopify-style simulation with a "⚡ Autofill Demo Student Info" shortcut, test payment card, and celebratory confetti order confirmation.
- **Demo Presentation Toolbar**: A floating drawer in the bottom-left corner allowing the team during university pitches to test out different brand names, taglines, or hero flavors live!
- **Centralized Brand Config**: Edit [`src/config/snackConfig.ts`](./src/config/snackConfig.ts) to replace all placeholders once final branding is decided.

## 🚀 Local Development
```bash
# Clone the repository
git clone https://github.com/Jhesse00/snack-co-storefront.git
cd snack-co-storefront

# Install dependencies
npm install

# Start local dev server
npm run dev
```
